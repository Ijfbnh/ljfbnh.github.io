
# История города Дружковка

## 1. Назначение проекта

Проект представляет собой многостраничный информационный сайт, посвящённый городу Дружковка Донецкой области. Цель сайта — познакомить посетителей с историей города, его инфраструктурой, культурой, достопримечательностями и интересными событиями.

Проект разработан в рамках лабораторной работы № 1 «Изучение HTML-тегов и CSS-стилей».

## 2. Использованные технологии

При разработке сайта использовались:

- **HTML5** — создание структуры и содержимого веб-страниц, применение семантических тегов и форм.
- **SCSS (Sass)** — написание стилей с использованием переменных, вложенности, миксинов и наследования через `@extend`.
- **CSS3** — оформление элементов, позиционирование, анимации, псевдоклассы и псевдоэлементы.
- **Адаптивная вёрстка** — обеспечение корректного отображения сайта на компьютерах, планшетах и смартфонах.
- **Emmet** — ускорение написания HTML-разметки.
- **Git и GitHub** — контроль версий и хранение исходного кода проекта.

Дополнительно использованы CSS-средства для создания персонажей South Park без применения изображений.

## 3. Структура страниц

Сайт состоит из следующих страниц:

| Страница | Содержание |
|---|---|
| `index.html` | Главная страница: краткое описание Дружковки, фотографии и интересные события. |
| `about.html` | Информация о разработчике, биография и навыки. |
| `history.html` | История города и хронология важных событий. |
| `infrastructure.html` | Географическое положение, административное деление, транспорт и карта города. |
| `culture.html` | Культурная жизнь города: музеи, учреждения, мероприятия и известные деятели. |
| `feedback.html` | Форма обратной связи с проверкой введённых данных. |

На всех страницах предусмотрено единое навигационное меню для удобного перехода между разделами.

## 4. Как запустить сайт локально

Для запуска проекта не требуется установка сервера или специального программного обеспечения.

1. Скачайте архив проекта и распакуйте его в удобную папку.
2. Откройте папку проекта.
3. Найдите файл `index.html`.
4. Откройте его в любом современном браузере (Google Chrome, Mozilla Firefox, Microsoft Edge и других).

Для просмотра SCSS-исходников можно использовать установленный Sass. Если требуется повторно скомпилировать стили, выполните команду:

```bash
sass scss/style.scss css/style.css
```

После компиляции откройте `index.html` в браузере.
