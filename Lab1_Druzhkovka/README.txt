ЛАБОРАТОРНАЯ РАБОТА №1 — ДРУЖКОВКА

Страницы: index.html, history.html, infrastructure.html, culture.html, developer.html, feedback.html.
Стили: css/style.css. Скрипт: js/main.js.

Запуск: распаковать архив и открыть index.html в браузере. Для разработки можно использовать Live Server.
В developer.html замените [Фамилия Имя Отчество] и [номер группы], добавьте своё фото, исправьте проценты навыков.
Галерея содержит 6 фотографий по внешним URL; необходим интернет и проверка условий использования изображений.
Карта встроена через OpenStreetMap. Новости главной страницы имеют даты публикаций 2026 года.
Форма демонстрационная: HTML5-валидация работает, но данные не отправляются на сервер.

Дополнительные функции: адаптивное меню, светлая/тёмная тема с localStorage, поиск по исторической таблице, динамический счётчик, интерактивная форма.
Если в методичке есть отдельный перечень усложнённого и дополнительного заданий, его нужно сверить с реализацией.
